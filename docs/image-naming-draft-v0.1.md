# 影像文件命名与书籍目录 口径件 v0.1

- 起草：**Zang 2026-10-11**（需求拆解件；规范由 **Jing** 后续按 §0.4 入册）
- 需求原文（Kevin 2026-10-11）：
  > 图片文件的命名规则：`P[页码]-C[列号]-R[行号]`；释义：P=Page 页面；C=Column 列；R=Row 行。`P299-C1-R3` ＝ 第 299 页，第 1 列，第 3 行。**在本地统一存放到书籍目录下。**

## 1. 现状实测（Zang；可复跑）

| 面 | 现命名 / 落点 | 说明 |
| --- | --- | --- |
| **印谱解析线**（印面） | `output/faces/<book_key>/p<页4位>_<序2位>.webp`（如 `output/faces/_/p0029_00.webp`） | 名称寻址；`stamps.img_path` 直接存该路径；现 **7354 件 / 126 MB** |
| **印章采集线**（TIFF） | `<sha256[:2]>/<sha256>.tiff`（`var/seal_images_tiff` / 就绪包 `images/` / `xiai/data/originals`） | **内容寻址**＝交付面契约（无 seqid/kind ⇒ 靠 `images_manifest.jsonl` 回指） |
| 书籍目录现状 | `output/faces/` 下只有 **`QHYD` / `TMP` / `_`** 三个键 | `book_key` 来自 `config/book_codes.json`；**未签简码的书落 `_`**（`秦印类编 检索版.pdf` 即此例，已列 R51 跨书覆盖风险） |

## 2. 关键难点实测：`C/R` 怎么推、会不会撞名

`stamps` 只有 `(x1,y1,x2,y2)`，**列/行必须从 bbox 推导**。在**已解析的真实数据**（`秦印类编 检索版.pdf`：**765 页 / 7183 枚**）上实测两种落法：

| 落法 | 含义 | 撞名 | 样例（页 400） |
| --- | --- | --- | --- |
| **秩次法**（推荐） | `C` ＝ 页面级列号（左→右，列级聚类）；`R` ＝ **该列内自上而下的位次** | **0 枚**（构造上唯一） | `P400-C1-R1 / C2-R1 / C3-R1 / C1-R2 …` |
| **行带法** | `C` 同上；`R` ＝ **页面级行带**（跨列对齐） | **1288 枚受影响（17.9%）、涉 481/765 页（63%）** ⇒ 需大面积加后缀 | 同一行带内多枚并列 ⇒ `P400-C2-R2-2` 之类 |

- 列级聚类口径（两法相同）：按 x 中心排序，**列间阈值 ＝ 中位印宽 × 0.6（下限 8 px）**；实测列数分布：C1 2608 / C2 2458 / C3 2085 / C4 32 枚 ⇒ 本书以 **1〜3 列**为主。
- 行位次分布：R1 2172 / R2 1908 / R3 1446 / R4 827 / R5 397 / R6 189 / R7 98 / R8 60 ⇒ 最长列 **8 枚**。
- 页 299 实例（6 枚）：`P299-C1-R1`（x1426,y1582）`P299-C2-R1`（x2148,y737）`P299-C1-R2`（x1428,y2426）`P299-C2-R2`（x2149,y2426）`P299-C2-R3`（y3166）`P299-C2-R4`（y3340）。

## 3. 口径（默认值；每处「一句话可改」）

1. **名字形**：`P<页码>-C<列号>-R<行号>`——**大写 P/C/R ＋ 短横**，**不补零**（照你原文：`P299-C1-R3`，不写 `P0299`）；扩展名沿用各自格式（印面 `-TIFF` 面 `.tiff`、webp 面 `.webp`）。
2. **`P` 口径** ＝ `stamps.page`（**1-based**，与你给的 `page_range`（`29–794`）**同一口径**）；**不用**书上印刷页码（当两者不同时以 `stamps.page` 为准，一句话可改）。
3. **`C`** ＝ **页面级列号**（左→右，`1` 起）。
4. **`R`** ＝ **该列内自上而下位次**（`1` 起；秩次法，**构造上唯一**）。
5. **书籍目录**：`output/books/<书名>/` —— **`<书名>` 取「模板名 / PDF 名规范化」**（去扩展名；与 `config/templates.json` 的键同源，便于回指）；**取代** `output/faces/<book_key>/` 的写法（`book_key` 缺失落 `_` 的老问题**一并对齐**）。
6. **红线**：**只许加法**（既有 7183 件 webp 与 6347 件 TIFF **不删不改**；新命名另出）；**印章采集线不改命名**（内容寻址 ＋ `images_manifest.jsonl` 回指是交付面契约）；**零联网**。

## 5. 验收候选（AC 候选底稿；可机械判负）

- **NB-1 名字形**：逐行正则 `^P[0-9]+-C[0-9]+-R[0-9]+\.(tiff|webp)$`；**无补零/无多余后缀**（除 R-d 裁定要求）。
- **NB-2 唯一性**：同书**页内 `(C,R)` 唯一**（逐页 `group by (page,C,R) having count>1` ⇒ 0 行）。
- **NB-3 `P` 一致性**：文件名 `P` 值 ＝ 该行 `stamps.page`（逐行核对，不得错位）。
- **NB-4 覆盖完整**：每枚印面在**书籍目录**下**恰有一个**文件（双向对账：库行 ↔ 文件，无孤儿无缺失）。
- **NB-5 目录口径**：文件落在 `output/books/<书名>/`；`<书名>` 与模板键同源。
- **NB-6 红线**：既有 webp / 印章线 TIFF **字节未动**（内容指纹）。
- **NB-7 幂等**：同 (page,C,R) 二次产出 ⇒ 字节稳定（sha256 不变）。
