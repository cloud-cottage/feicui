# 书目元数据校验（ISBN / CIP）· 口径件 v0.1

> 起草：Zang（2026-10-11）｜性质：**Kevin 三阶段方案的需求拆解 ＋ 分层设计 ＋ 待确认项**；规范入册由 Jing 按 `docs/feicui.spec.md` §0.4 流程执行。
> 需求输入：Kevin 2026-10-11 原话（§1 照登）。

## 1. 需求（Kevin 原话，照登）

> **阶段 1：开发原型（现在可直接做）**
> - 主校验：**商用 ISBN API（极速 / 聚合）** 处理现代篆刻新书 ISBN+CIP
> - 辅助校验：OLCC Z39.50 测试账号（可先申请试用）
> - 本地库：内置 ISBN 校验算法、CIP 核字号正则校验，**先做本地第一层校验**
> - 豆瓣只读封面简介，不参与元数据校验
>
> **阶段 2：正式上线，专题图书馆资质落地**
> 1. 申请 **OLCC 全国图书馆联合编目中心成员馆**（公益性专题图书馆可申请），拿到 Z39.50 正式权限，获取金石古籍 MARC 数据
> 2. 商务对接 PDC，签约官方 ISBN/CIP 接口，替换第三方 API 作为权威基准源
> 3. 批量导入印谱专题书目（《公私藏印谱综录》等）作为本地特色库，处理无 ISBN 古籍
>
> **阶段 3：长期优化**
> - 建立**来源可信度权重**：PDC > OLCC/CALIS MARC > 第三方 ISBNAPI > 豆瓣；多源冲突时按权重提示编目员

## 2. 现状盘点（Zang 实测，2026-10-11）

| 能力 | 现状 |
|---|---|
| **PDF 文本层读 ISBN** | **能，但只看书**：`秦汉印典` 第 2 页文本层直接有 `ISBN 7-80635-095-0`（其目录键 `7806350950` 即由此来）；`古玺汇编` 文本层无 |
| **扫描件（无文本层）** | **必须 OCR 版权页**：`秦印类编 检索版` 851 页、文本层抽查 18 页仅 1 页有文本 ⇒ 文本层读不到；**OCR 实测命中**：第 850 页读出 `ISBN 978-7-5508-4722-4`（出版社=西泠印社出版社）、第 851 页另有纯数字形 `9787550847224` |
| **OCR 代价（实测）** | 400 dpi 单页 **42–60 s**；**200 dpi 单页 19.8 s（省 2.9×）且 ISBN 照样命中** ⇒ 版权页类纯文字页应用 200 dpi |
| **ISBN 校验算法** | **已有且已验证**（ISBN-10 / ISBN-13 校验位；`9787550847224` 加权和 136、校验位 4 ⇒ 通过；`7806350950`/`7501007985` 亦通过）—— 目前只以临时脚本形式存在，**未入库为模块** |
| **CIP 核字号校验** | **无**。实测样本（OCR 原文）：「**中國國家版本館CIP數據核字第2025WX8837號**」⇒ 可据实构造正则 |
| **商用 API / Z39.50 / MARC / 豆瓣** | **均无**（无适配层、无密钥、无资质） |
| **目录键** | `config/book_dir_keys.json` 为**人工登记**；`dir_key_source ∈ {ISBN, chinese_title, pdf_name_unconfirmed}`；`秦印类编 检索版` 现落 `chinese_title`（因自动识别未做） |

## 3. 分层设计（照 Kevin 权重，自低到高）

| 层 | 来源 | 用途 | 联网 | 阶段 |
|---|---|---|---|---|
| **L0 本地** | ① ISBN 校验算法（10/13 位）② **CIP 核字号正则** ③ 版权页 OCR 抓取（ISBN / CIP / 出版社 / 年份 / 书名候选）④ 本地特色库（印谱专题书目） | **第一层校验**：格式合法性 ＋ 交叉自证（校验位、出版社前缀与 OCR 出的出版社是否一致） | 否 | **1（现在做）** |
| **L1 商用 API** | 极速 / 聚合（ISBN+CIP 查询） | 现代篆刻新书主校验 | 是（限速） | 1（适配层）／2（定供应商） |
| **L2 OLCC / CALIS MARC** | 全国图书馆联合编目中心 Z39.50（先申请**测试账号**，阶段 2 拿成员馆权限） | 辅助校验；金石古籍 MARC | 是 | 1（申请）／2（正式） |
| **L3 PDC 官方** | 签约官方 ISBN/CIP 接口（阶段 2 商务） | **权威基准源**（替换第三方） | 是 | 2 |
| **X 豆瓣** | 封面 / 简介**只读** | **仅展示，不参与元数据校验**（Kevin 明示） | 是（只读） | 1（登记） |

**冲突处理（阶段 3）**：按权重 `PDC > OLCC/CALIS MARC > 第三方 ISBNAPI > 豆瓣` 取高；**多源冲突时不静默取一**，落「冲突记录」并**提示编目员**人工确认（人工确认结果回写为最高优先并留痕）。

## 4. 数据落点与字段（口径）

- **新库**：`var/biblio_ingest.db`（与 `person_ingest.db` / `item_ingest.db` / `seal_ingest.db` 同型，**不写 `yinpu.db`**）。
- **主表 `book_biblio`**：`book_ref`（书名 / 文件指纹）｜`isbn13` / `isbn10`（规范化去连字符）｜`cip_code`（核字号）｜`title` / `publisher` / `pub_year` / `edition`｜`source`（`local_ocr` / `jisu` / `juhe` / `olcc` / `pdc`）｜`verify_state`（`ok` / `checksum_fail` / `conflict` / `unverified`）｜`evidence`（OCR 片段 / API 原始响应）｜`created_at`。
- **目录键联动**：`config/book_dir_keys.json` 的 `dir_key_source` 保持 `ISBN`，新增**子来源**字段（如 `isbn_source: local_ocr|api_jisu|…`）以便审计；**目录键切换（改名 ＋ 改写既有行路径）属独立动作，并入「重出轮」执行**（Zang 建议，一句话可改）。
- **红线**：密钥**不入仓**（走环境变量 / 保险库）；不写 `yinpu.db` 既有列值；联网一律**服务端**且**礼貌限速**、**失败不阻塞主交付**；豆瓣只读且不参与校验链。

## 5. 阶段 1 可立即执行清单（本单已派实现）

1. **`server/app/biblio.py`**：ISBN 规范化（去连字符 / 大小写 X）＋ ISBN-10 / ISBN-13 校验位 ＋ **CIP 核字号正则**（样本锚：`中國國家版本館CIP數據核字第2025WX8837號`；兼容 `核字第2025WX8837號` / 简体「核字第…号」）。
2. **版权页定位与抓取**（复用 `processor.render_page` ＋ 既有 OCR）：扫描面 ＝ 前 6 页 ∪ 末 4 页；**200 dpi**；锚词 `ISBN` / `圖書在版編目` / `在版编目` / `CIP` / `核字`；输出候选 ＋ 证据片段。
3. **交叉自证**：ISBN 校验位通过 ∧ **出版社前缀与 OCR 出的出版社一致**（如 `5508`＝西泠印社出版社）⇒ `verify_state=ok`；不一致 ⇒ `conflict` 并保留双方证据。
4. **目录键推荐**：按 L0 结果给出 `dir_key` 建议（ISBN 优先）＋ 建议来源标记。
5. **L1 适配层骨架**：配置驱动（供应商 / 端点 / 超时 / 限速），**密钥缺失即跳过并标 `unverified`**（不得伪造成功）；本单不接真网。
6. **豆瓣只读封面/简介**：仅登记接口形态与缓存位（**不进校验链**）。
7. **实证**：用 `秦印类编 检索版`（第 850/851 页）跑通 ⇒ 期望输出 `isbn13=9787550847224`、`publisher=西泠印社出版社`、`verify_state=ok`；并对 4 本已登记书出一张「识别 vs 现目录键」对照表。
