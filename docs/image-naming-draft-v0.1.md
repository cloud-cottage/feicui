- 需求原文（Kevin 2026-10-11）：
  > 图片文件的命名规则：`P[页码]-C[列号]-R[行号]`；释义：P=Page 页面；C=Column 列；R=Row 行。`P299-C1-R3` ＝ 第 299 页，第 1 列，第 3 行。**在本地统一存放到书籍目录下。**

| 面 | 现命名 / 落点 | 说明 |

| **印谱解析线**（印面） | `output/faces/<book_key>/p<页4位>_<序2位>.webp`（如 `output/faces/_/p0029_00.webp`） | 名称寻址；`stamps.img_path` 直接存该路径；现 **7354 件 / 126 MB** |
| **印章采集线**（TIFF） | `<sha256[:2]>/<sha256>.tiff`（`var/seal_images_tiff` / 就绪包 `images/` / `xiai/data/originals`） | **内容寻址**＝交付面契约（无 seqid/kind ⇒ 靠 `images_manifest.jsonl` 回指） |

## 2. 关键难点实测：`C/R` 怎么推、会不会撞名

`stamps` 只有 `(x1,y1,x2,y2)`，**列/行必须从 bbox 推导**。在**已解析的真实数据**（`秦印类编 检索版.pdf`：**765 页 / 7183 枚**）上实测两种落法：

| 落法 | 含义 | 撞名 | 样例（页 400） |
| --- | --- | --- | --- |
| **秩次法**（推荐） | `C` ＝ 页面级列号（左→右，列级聚类）；`R` ＝ **该列内自上而下的位次** | **0 枚**（构造上唯一） | `P400-C1-R1 / C2-R1 / C3-R1 / C1-R2 …` |
| **行带法** | `C` 同上；`R` ＝ **页面级行带**（跨列对齐） | **1288 枚受影响（17.9%）、涉 481/765 页（63%）** ⇒ 需大面积加后缀 | 同一行带内多枚并列 ⇒ `P400-C2-R2-2` 之类 |

- 列级聚类口径（两法相同）：按 x 中心排序，**列间阈值 ＝ 中位印宽 × 0.6（下限 8 px）**；实测列数分布：C1 2608 / C2 2458 / C3 2085 / C4 32 枚 ⇒ 本书以 **1〜3 列**为主。
- **行位次分布**：R1 2172 / R2 1908 / R3 1446 / R4 827 / R5 397 / R6 189 / R7 98 / R8 60 ⇒ **最长列 ≠ 8**：早先只打印了前 8 项（**截断假象**），**实测全分布延到 R15**（最长列 ＝ 页 791 的 C3，15 枚）。**更正（Kong `1f8f7c3` 报、Zang 采纳）**。
- 页 299 实例（6 枚）：`P299-C1-R1`（x1426,y1582）`P299-C2-R1`（x2148,y737）`P299-C1-R2`（x1428,y2426）`P299-C2-R2`（x2149,y2426）`P299-C2-R3`（y3166）`P299-C2-R4`（y3340）。

## 3. 口径（默认值；每处「一句话可改」）

1. **名字形**：`P<页码>-C<列号>-R<行号>`——**大写 P/C/R ＋ 短横**，**不补零**（照你原文：`P299-C1-R3`，不写 `P0299`）；扩展名沿用各自格式（印面 `-TIFF` 面 `.tiff`、webp 面 `.webp`）。
2. **`P` 口径** ＝ `stamps.page`（**1-based**，与你给的 `page_range`（`29–794`）**同一口径**）；**不用**书上印刷页码（当两者不同时以 `stamps.page` 为准，一句话可改）。
3. **`C`** ＝ **页面级列号**（左→右，`1` 起）。
4. **`R`** ＝ **该列内自上而下位次**（`1` 起；秩次法，**构造上唯一**）。
5. **书籍目录**：`output/books/<书名>/` —— **`<书名>` 取「模板名 / PDF 名规范化」**（去扩展名；与 `config/templates.json` 的键同源，便于回指）；**取代** `output/faces/<book_key>/` 的写法（`book_key` 缺失落 `_` 的老问题**一并对齐**）。
6. **红线**：**只许加法**（既有 7183 件 webp 与 6347 件 TIFF **不删不改**；新命名另出）；**印章采集线不改命名**（内容寻址 ＋ `images_manifest.jsonl` 回指是交付面契约）；**零联网**。

## 5. 验收候选（AC 候选底稿；可机械判负）

- **NB-1 名字形**：逐行正则 `^P[0-9]+-C[0-9]+-R[0-9]+\.(tiff|webp)$`；**无补零/无多余后缀**（除 R-d 裁定要求）。
- **NB-2 唯一性**：同书**页内 `(C,R)` 唯一**（逐页 `group by (page,C,R) having count>1` ⇒ 0 行）。
- **NB-3 `P` 一致性**：文件名 `P` 值 ＝ 该行 `stamps.page`（逐行核对，不得错位）。
- **NB-4 覆盖完整**：每枚印面在**书籍目录**下**恰有一个**文件（双向对账：库行 ↔ 文件，无孤儿无缺失）。
- **NB-5 目录口径**：文件落在 `output/books/<书名>/`；`<书名>` 与模板键同源。
- **NB-6 红线**：既有 webp / 印章线 TIFF **字节未动**（内容指纹）。
- **NB-7 幂等**：同一 `(page,C,R)` 二次产出 ⇒ **解码像素逐字节相同**（**★ 不得按文件 sha256 判**——见下 §7 之 2：Pillow `tiff_deflate` 在大图上逐字节非确定）。

## 7. 命名地基交付与两则复核（Kong `1f8f7c3`；Zang 复核 2026-10-11）

**交付**：`server/app/naming.py`（纯函数；`assign_cr` / `name_for` / `dir_key_for` ＋唯一性断言）｜`config/book_dir_keys.json`（加法，待入册）｜页 299/400 **样例 16 件**已落 `output/books/秦印类编 检索版/P<页>-C<列>-R<行>.tiff`（**本样例未校正**）｜自检 **34/34 PASS**（7183 枚页内 `(C,R)` **0 冲突**、列数分布对上、16 件名逐条匹配正则、裁图尺寸＝库内 bbox、`idx` 序与 `(C,R)` 序 **742/765 页不同** ⇒ 证明不是简单用 `idx`）。

1. **R 分布截断假象（已更正，见 §2）**：最长列实测 **15**（页 791 C3），非 8。
2. **★ Pillow `tiff_deflate` 在大图上逐字节非确定（Kong 报，Zang 独立复现）**：
   - 复现读数：**`800×1288 RGB`（3 MB 载荷）12 次编码 ⇒ 5 个不同 sha256**；而 **1×1 / 3×3 / 5×7 / 33×65 / 120×160 / 241×321 / 121×161(L) / 17×23(L) 全部唯一**（各 12 次）⇒ **确定性依尺寸而定，阈值待定**（已知 232 KB 级确定、3 MB 级非确定）。
   - 机制（Kong 定位）：差异落在**末 strip 数据尾与 IFD 之间的 1 byte 填充**（未初始化）；实测 `末 strip 尾=195931 / IFD=195932`。
   - **后果与处置**：① **验收候选 NB-7 改为「解码像素逐字节相同」**（不得按文件 sha256）；② **登记 R61**：**内容寻址面**（印章线 `tiff_sha256` ／ xiai 影像库的 sha256 键）在大 TIFF 上可能「同像素、不同键」⇒ 重复入库 / 去重失效；缓解方案候选：(a) 索引键改用**解码像素哈希**；(b) 写入后**把填充字节规范化置零**；(c) 换确定性编码器（如 `tifffile`）；**本单不动印章线**（R58 已另立），只登记。
   - **对本轮范围的影响**：印谱线印面图小（现样例 1.98 MB / 16 件，单张 ≪ 1 MB）⇒ **不受影响**；真正确险的是印章线那 6 张 >4 MiB 的图。

### 6.1 据此的落地清单（只印谱解析线）
1. **命名推导**（新 `server/app/naming.py`，纯函数）：列级聚类得 `C`（阈值＝中位印宽×0.6、下限 8 px）＋ 列内 `y` 排序得 `R` ⇒ 逐枚 `(C,R)`，页内**唯一**（自检断言）。
2. **目录键**（新 `config/book_dir_keys.json`，加法）：`PDF 名 → 目录键`；已知两本落 ISBN，其余落中文书名（去扩展名规范化）；未登记 ⇒ 回落 PDF 名并**逐条标记**（如 `tmp.pdf` 身份未确认）。
3. **落点**：`output/books/<目录键>/P<页>-C<列>-R<行>.tiff` 与同名 `.webp`（并存）。
4. **回填**（既有 7183 枚）：**从 PDF 重裁**（无损路径，不用既有 webp 二次压缩）；PDF 不在盘或路径失效者**逐条进失败清单**、不得静默跳过。
5. **落库**：`stamps` **加法列** `col` / `row`（＋已规划的 `img_path_tiff`）；**`img_path` 不动**。
6. **颜色校正**（另一条工况）：与命名同轨施加（口径见 §2.2）；**待 Kevin 定「整体变冷接受 or V1b」**后可合并产出。
