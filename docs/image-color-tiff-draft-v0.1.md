### 1.2 当前主色调 vs 目标色（抽样 8 张 TIFF 实测）
- 目标 **`#C95021` ＝ rgb(201, 80, 33) ＝ HSV(17°, 0.84, 0.79)**。
- 现图**印泥像素**实测 HSV(8°–36°, **0.27–0.55**, 0.71–0.87)、均值约 `rgb(206, 130, 110)` ⇒ **偏淡偏粉、蓝通道过高**（需大幅提饱和、压蓝）。
- **印泥占比跨度极大：0.9% ～ 78%**（0.9% 那张是 800×1288 的边款/释文图）⇒ **低占比必须兜底**，否则等于拿纸当主色调。
- 全图均值/量化众数多为**纸色**（如 `(232,216,184)`）⇒ 若按「全图均值」定义主色调，会把纸染红（**已排除该定义**）。

## 2. 口径（默认值；每处标「一句话可改」）

### 2.1 适用范围（两条线都做）
- **印章采集线**：对 **6347 张 TIFF** 做颜色校正后**重出**（新 sha256 ⇒ 新文件，**不覆盖**旧文件）。
- **印谱解析线**：印面图**输出 TIFF**（Kevin 明确要求）＋ 同样做颜色校正。
  - **默认：与 webp 并存**（红线「只许加法」⇒ 既有 7183 件 webp **不删不改**；新 job 同 (page,idx) 同时产 `.webp` ＋ `.tiff`）。**待裁 R-a**：webp 是否退场。

### 2.2 校正算法 V1（印泥锚点白平衡；逐图）
1. **印泥掩膜**：`r > g+15` 且 `r > b+15` 且 `S > 0.25`（S ＝ (max−min)/max）。
2. **质心** `C` ＝ 掩膜内像素均值（＝本件定义的「主色调」）。
3. **锚点映射**：求通道增益 `k = target / C`（在**线性 RGB** 中计算、sRGB 往返），**clamp `k ∈ [0.5, 2.0]`**，整图施加同一变换 ⇒ **纸保持中性**（不被染色）。
4. **跳过与兜底**：`ink_ratio < 2%` ⇒ **不校正**，逐行标 `color_correction: "skipped(ink_ratio=<值>)"`（**不得静默**）。**待裁 R-c**：阈值 2% 是否合适。
5. 目标色 **`#C95021` ＝ rgb(201,80,33)**（唯一常量、单点可改）。

### 2.3 容器 / 命名 / 落库
- 容器沿用**家法**：**RGB 8-bit ＋ Deflate 无损**（与印章线同口径；不得 JPEG-in-TIFF、不得有损）。
- 印章线：沿用**内容寻址** `<sha256[:2]>/<sha256>.tiff`（sha256 ＝ **TIFF 字节**）；`images_manifest.jsonl` 加 `color_correction` 字段（记录 applied/skipped ＋ 前后质心与 ΔE）。
- 印谱线：建议 `output/faces_tiff/<book_key>/p<页4位>_<idx2位>.tiff`（与 webp 同构、**名称寻址**，便于按页/序回指）。**待裁 R-b**。
- 落库：`stamps` **加法新增列** `img_path_tiff`（**不得 drop/rename 现有列**）；**E6 取图端点本轮不扩**（预览仍走既有 PNG/webp）。

### 2.4 重出 / 回填 / 入库
- 印章线：**本地重出 6347 张**（无网）＋ 重出就绪包 ＋ **重新入库 xiai 影像库**（5191，单张 ≤ 4 MiB）。
- 印谱线：**新 job 默认双份输出**；**历史 7272 行印面是否回填 TIFF** ＝ **待裁 R-d**（**默认不回填**：老 job 的 `pdf_path` 多已失效，回填需单独批次）。

### 2.5 红线
1. **只许加法**：不动既有 6347 件 TIFF、不动 7183 件 webp、不改 `stamps` 现有列语义、不改 E1〜E10 契约。
2. **零联网**（印章线源 JPEG 已在本地）。
3. 校正**纯函数**、两侧共用**同一份实现**（不得在 worker 侧与接口层各写一份）。
4. 跳过/裁剪等**任何降级都必须逐行标记**，不得静默（承既有 AC-54 的同一纪律）。

## 4. 验收候选（AC 候选底稿；可机械判负 —— 由 Neng 执行）
- **CA-1 校正可复算**：对**未跳过**行，校正后印泥质心 → `#C95021` 的 **ΔE2000 ≤ 5**；并给出**校正前**同口径 ΔE 作对照（证明真的降了）。
- **CA-2 纸保中性**：纸区均值色的**色相偏移 ≤ 阈值**（不得把纸染红；给校正前后读数）。
- **CA-3 容器与无损**：逐行 TIFF 魔数成立 ＋ `compression` ∈ Deflate 族 ＋ 无有损痕迹；单张 ≤ 4 MiB（交 xiai 的那一份）。
- **CA-4 一一对应**：`images_manifest.jsonl` ↔ `images/**` **双向无孤儿无缺失**（给两个方向的计数）。
- **CA-5 跳过可见**：`ink_ratio < 阈值` 的行**逐行标记** `skipped(ink_ratio=…)`，且**不得**被当成校准失败。
- **CA-6 幂等**：同一张图二次校正**字节稳定**（sha256 不变）。
- **CA-7 印谱线双份**：新 job 同 (page,idx) 同时产出 `.webp` 与 `.tiff`，且 `img_path_tiff` 落库；TIFF 与 webp **像素尺寸一致**。
- **CA-8 单一实现**：校正算法只有**一份**实现（`grep` 判负第二份）。
