# O 件成品化（宣纸画布）· 算法特征拆解与样张 · v0.1

> 需求：Kevin 2026-10-11 给定一段**面向生成式图像模型**的提示词，要求「从中辨别算法特征，力求与原提示词的效果一致」。
> 本件＝把提示词拆成**确定性图像处理算法**（可复现、不引生成模型），先出 **10 张样张**供比对选型。
> 实现：`server/app/seal_canvas.py`（≈820 行，纯函数）｜样张驱动：`ops/seal-canvas/run_samples.py`。

## 1. 提示词 → 确定性算法（逐条映射）

| 提示词条款 | 算法实现 | 验收读数（见 §3） |
|---|---|---|
| 印章本体 100% 冻结（红区/白线/轮廓/字法/形状，不重绘不改形） | **零色彩处理**；唯一允许的像素变化＝几何重采样，用 **Lanczos** 最高保真缩放 | A 口径 **印区逐像素差 = 0**（位级一致）；往返 SSIM 0.9975–0.9992 |
| 背景替换为白色宣纸底纹（细弱纤维肌理、柔和、不抢主体） | 程序化生成：固定种子的**长轴各向异性纤维 ＋ 细颗粒**，色域裁剪到 **`#FAFAF7`–`#FFFFFF`**，无暗角/无阴影/无重复纹理 | 角部实测色域 `[250,250,247]–[255,255,255]`；背景中印泥像素 **0** |
| 全局均匀柔光、无明显明暗差 | 仅背景亮度均匀化，**不对印章做任何光影处理** | 同上（背景无非均匀照明） |
| 印泥微晕染：仅红掩膜最外缘、极轻微，不侵入本体 | 仅在掩膜**外侧 1–3 px 环带**叠加该印自身印泥色均值，**α ≤ 8%**；掩膜内一律 0 | 晕染内 = **0.0**；晕染峰值 = **0.08**（=α 上限） |
| 色彩校准（红色均匀度） | ⚠️ 与「冻结」冲突 ⇒ **默认不做**（见 §4 待裁） | —— |
| 主体缩小至「最大边长 = 总边长 × **62%**」并居中 | 画布最长边 **1200 px**、纵横比沿用原片；主体最长边 = 62%×1200 = **744 px**，居中 | 62% 实测 **0.6200**；居中偏差 **≤0.5 px** |
| 输出最长边 1200 px、另一边按比例 | 同上；容器 **TIFF · RGB 8-bit · Deflate ＋ Predictor=2**（与 O 件同容器） | 长边实测 **1200**；`Compression=8 & Predictor=2` |

## 4. 待裁项（Kevin 定）

- **W-1 色彩校准**：提示词的「调整红色印泥色彩均匀度」与「本体 100% 冻结」**直接冲突** ⇒ 现默认**不做**。若要，可给极轻的 red 通道 gamma，但**必然破坏位级冻结**。
- **W-2 B 口径的晕染落点**：B 的环带会落在被贴上的原片纸上 ⇒ 违「冻结」。已留 `halo_policy` 开关（`seal`/`paper`）。
- **W-3 `fill_holes` 开关**：掩膜空洞填充对「白文印内部白线」的影响需按你的观感定；现默认按提示词「严禁触碰内部白线」保守处理。
- **W-4 输出形态**：成品是为**展示/封面**用（1200 px、宣纸底），与**入库/交付**用的 O 件（400 dpi 原尺寸）是两条面 —— 是否只作展示面？（默认：是，**不替换 O 件**。）
