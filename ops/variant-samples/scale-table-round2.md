## 0. 豆包标定算式
- 纸纹理：`f_d = 1.2223mm`（＝W_o × f_d/W_d）；粗纤维带峰值 1.2223mm、细纤维带 0.4074mm、颗粒带 0.1294mm；各向异性 长/短＝1.749（由参照图自相关 x:y 实测）
- 幅度：octave 幅度比（酉矢）＝mottle 0.20422 / coarse 0.40844 / fine 0.60745 / grain 0.64998（由参照图分带 RMS 比 [1.0594, 1.5756, 1.6859]）；纸底总 RMS 目标 3.593（0–255）
- 印泥：语义 L* 曲线 [60.318, 49.67, 48.826, 48.83, 48.853, 48.68] @ dn [0.0835, 0.25, 0.4165, 0.5835, 0.75, 0.9165]；颗粒高通 σ 目标 7.9735；边缘过渡 0.0598mm；晕染过渡 0.0648mm / 外沿 0.6572mm
