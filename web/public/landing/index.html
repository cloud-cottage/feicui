macOS：打开 DMG 把「斐萃」拖进「应用程序」，首次右键 App →「打开」（未签名，仅需一次）
Windows：解压整个目录后双击 斐萃_lite\斐萃.exe —— 不要单独拷出 exe，需已装 WebView2

Windows 详细安装教程（点开 / 收起）
  1. 下载并完整解压：右键 zip →「全部解压缩」。必须保留整个目录（斐萃_lite 与 _internal），只把 斐萃.exe 单独拖出来将无法启动。
  2. 双击运行：进入 斐萃_lite 文件夹，双击 斐萃.exe。
  3. SmartScreen 提示（首次）：本程序未做数字签名，Windows 会提示「已保护你的电脑」→ 点 「更多信息」→「仍要运行」（属正常现象）。
  4. 杀毒软件提示：个别杀软可能误报，选「允许 / 加入信任列表」即可。
  5. WebView2 运行时：Windows 10/11 一般已内置。若双击后一闪而过、没有窗口，需安装一次： 微软官网 · WebView2 运行时（常青版安装程序），装完重新双击即可。
  6. 数据保存在哪：%APPDATA%\斐萃（首次运行自动创建，无需配置；卸载直接删目录）。

Windows 精简版（斐萃_lite）不含 OCR（印章文字识别）功能，其余与 macOS 精简版一致；含 OCR 的专业版（斐萃_pro，macOS，约 150 MB）见上方第三个按钮（跳 GitHub Release 下载）。

两个包怎么选：只要归档、切图、命名 ⇒ 下 斐萃_lite（94 MB，站内直链，最快）； 要印面释文 OCR 识别与纠错建议 ⇒ 下 斐萃_pro（150 MB，含 RapidOCR，跳 GitHub Release 页）。 使用说明 ↓

快速上手

  1. 下载并解压客户端到本地任意目录
  2. 双击启动 —— 直接打开本地桌面窗口（PyWebView，**无需浏览器、不监听端口**）
  3. 使用账号登录（管理员 / 操作员），口令由本机后端校验
  4. 选择本地 feicui 目录（百度网盘企业同步目录），校验通过后进入主界面
  5. 按三个页签作业：1_Original_PDF（原件盘点 / 元数据）→ 2_HighRes_PDF（整页 1200 dpi 48bit 生成，异步 + 进度 + 可取消）→ 3_Cropped_Tiff（印面切片浏览 / 测试件）

运行形态

本地封装分发版是桌面原生窗口（PyWebView）：不打开浏览器、不监听任何端口， 界面资源全部随客户端本地自带（零外链）。

⚠️ 本页面仅提供下载和说明；所有文件操作均在你本机完成，不会上传到公网。

账号说明

  • 默认口令随客户端文档提供，首次运行后请立即修改
  • ⚠️ 为安全起见，本公网页不列出具体账号与口令

v1.1.02026-10-20 · 切图台字段识别与命名升级
  • 切图台三字段自动识别（tab2）：每枚印自动带出释文 / 状态字 / 编号，三列在画布旁可逐枚就地编辑；识别分低于 0.95 且未经多数票确认者标「待复核」，只提示不改字
  • 阅读顺序（tab2 / tab1 元数据共用）：auto（按编号序列自动推断，编号即版序）或人工指定 rtl-ttb / ltr-ttb / rtl-btt / ltr-btt；决定列号 C 与行号 R 的方向（右列/左列、上行/下行谁先），优先序「人工 ＞ 编号推断 ＞ 书级元数据 ＞ 兜底」
  • 切片文件名升级：编号_P页码_C列_R行_释文_朝代_作者.tiff（例 0424_P370_C1_R1_中羞行府_清中期_吳熙載.tiff；空字段写 NA 保持位置稳定）；无编号自动回落旧名 P<页>-C<列>-R<行>.tiff，老批次不受影响
  • tab3 兼容新命名：裁切件页签按新名 / 旧名 / -O 原始切片三形态都能解析出页·列·行，混合目录照常浏览
  • 两个包改名：无 OCR 的 斐萃_lite（macOS 94 MB / Windows 94 MB，本页站内直链）／含 RapidOCR 的 斐萃_pro（macOS 约 150 MB，超网页单文件上限，跳 GitHub Release 下载）；旧名 斐萃-s1 / 斐萃-s2 退役
  • 纠错口径收紧：只认权威词表与同页多数票 ≥ 3，禁止猜测式改字（曾把正确的「中羞行府」误改成「中差行府」）
