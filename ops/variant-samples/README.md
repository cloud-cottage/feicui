## 2. 四版口径

### A｜现行基线复刻（产线真产物，**非重实现**）
底图**直接取自** `output/2_HighRes_PDF/9787550847224/P29-2400dpi-48bit.tif`（`render_page_2400.py` 主版：
宣纸换底 ＋ 掩膜外缘晕染 α≤8% ＋ 印泥色度校准 0.35）裁区 ÷4。
- 区域抽检：整页流式 ÷4 与 `crop_c2r1.extract_region_u16` **独立 strip 裁取 ÷4 逐像素一致 = True**。
- 读数（C1 红墨区）：L* μ/σ = 139.9 / **22.62**，a*σ 12.39，b*σ 10.75。
  ★ **注意**：产线校准把印泥 **L\* 方差从源图 21.19 抬到 22.62**（色度方差降 15.79→12.39 属预期）——
  即现行算法**色度更匀但明度更花**，这正是「扫描斑驳感」的来源之一。

### B｜钤盖均匀版
源渲染底图 → 宣纸换底（**单层**：`seal_canvas` 的 `BG_*` 色域/种子/幅度常量 ＋ `render_page_2400` 位置哈希
机制，晶格按 600dpi 换算 16/2 px）→ 印泥色度校准（`render_page_2400.color_uniformity`，0.35，保 ΣRGB）
→ **【新增】红墨区保边平滑**（guided filter，guide＝亮度，radius 8px@600dpi ≈0.34 mm，eps 1500，
**先校准后平滑**——探针实测该顺序使 L*/a*/b* 三项方差相对源图同时下降）。
- 冻结：白线区 45,147 px、掩膜外 24,940,170 px 对「本版观感基线」逐像素差 **= 0** ✓
- 读数（C1）：L* σ 21.19→**19.17**、a*σ 15.79→**12.09**、b*σ 13.94→**10.38**；红区高频斑驳能量 −14%。
- 纸底：mean (252.7, 252.7, 250.3)、高频 1.57（与 A 同档、略多颗粒）。

### C｜实拍观感版（＝B ＋ ①②③）
- ① **低频光场估计与去除**（全局，σ=25px@600dpi ≈1 mm，纸区低频场归一到 p90，增益限幅 [0.85, 1.15]）
  ——**作用于扫描态、先于换底**：实测增益 0.993–1.069、纸区均值 1.014 ⇒ 扫平扫描光照不均/暗角。
- ② **全局色调映射**：白平衡（gains 由 `colorcal.whitebalance_gains_for` 真源给出，实测 [1.015, 1.034, 1.140]，
  把扫描暖纸 (253.3, 251.3, 240.7) 推向白）＋轻柔 S 曲线（t=0.15）＋微对比（0.10，σ=6px）。
- ③ **宣纸纹理升级**：双层纤维（16/2 ＋ 64/8 px 晶格）＋颗粒 ＋ 新纸底微对比（0.12）＋
  极轻渗透感（换底纸底上 α≤5%、τ=6px、外缘 4–24px 环带，色＝印泥均值）。
- 冻结同上 ✓（结构算子仍只写红墨区）。
- 读数（C1）：L* μ/σ 147.2 / **20.97**、a*σ 14.31；纸底 mean (252.68, 252.67, 250.39)，高频 **1.649**（四版最高）。

### D｜重质感版（＝C ＋ 红墨区重质感 ＋ 纸底彻底净化）
- **【新增】红墨区重质感渲染**：距白线/边缘距离场（L2，d0=12px@600dpi ≈0.51 mm）做浓淡渐变
  （边缘增浓，实测平均增浓 **6.72%**）＋确定性微噪声（位置哈希，±1.8/255）。
- **【新增】纸底彻底净化**：换底区放宽到「gray ≥ 165 ∧ sat ≤ 0.30」（B/C 用生产判据 gray ≥ 210 ∧ sat ≤ 0.15），
  但**保护文字及其抗锯齿圈**（gray < 150 的核心 ＋ 2px dilate 保护区）。整页实测：候选背景中未换底残点
  **77,299 px（B/C）→ 6,965 px（D，−91%）**，且保留的正是近印淡红渗色（属自然渗色）。
- 冻结同上 ✓。读数（C1）：L* μ/σ 135.5 / **16.51**（方差最低，边缘增浓使整体偏深）、a*σ 14.54。

## 6. 溯源与已知偏差

- 源同一性：`output/1_Original_PDF/秦印类编 检索版.pdf` 页 29 内嵌 JPEG（xref 112）
  md5 `4b45bfe1a899e69e0ecb3dbe1751b18a` ＝ 产线 `ops/book-page-2400/readings-P29-2400dpi-48bit.json`
  记录值 **True** ⇒ A（产线底）与 B/C/D（本次底）**同源**。
- ⚠ **核实说明（未修脚本）**：`ops/book-page-2400/render_page_2400.py` 的 `PDF` 常量仍指向
  `inbox/20261011/秦印类编 检索版.pdf`——该文件在「output 四总目录」迁移后**已不存在**（现件在
  `output/1_Original_PDF/`）。本单**未改**该脚本，只以内嵌 JPEG md5 证同源；正式实现单建议顺手改常量。
- 观感算子为全局（提示词②许可），故白线区**像素值**会被光场/色调整体作用（幅度登记在
  `variants.C/D.tone_map`、`light_field`），但**零结构改动**（几何/字形/拓扑不变）。
- C/D 的印泥校准对越域像素跳过（与产线同口径，跳过 29.3 万 px——全局映调后越界像素增多）。
- 本单**不含**：整页 2400dpi 重出、DB/job 写入、`output/books` 或 `2_HighRes_PDF` 改动。
