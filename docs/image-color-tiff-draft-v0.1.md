## 2. 口径（默认值；每处标「一句话可改」）

### 2.1 适用范围（两条线都做）
- **印章采集线**：对 **6347 张 TIFF** 做颜色校正后**重出**（新 sha256 ⇒ 新文件，**不覆盖**旧文件）。
- **印谱解析线**：印面图**输出 TIFF**（Kevin 明确要求）＋ 同样做颜色校正。
  - **默认：与 webp 并存**（红线「只许加法」⇒ 既有 7183 件 webp **不删不改**；新 job 同 (page,idx) 同时产 `.webp` ＋ `.tiff`）。**待裁 R-a**：webp 是否退场。

### 2.2 校正算法 V1（**v0.1 修订 2：双锚点仿射 ＋ 核心质心**；逐图）
1. **印泥掩膜**：`r > g+15` 且 `r > b+15` 且 `S > 0.25`（S ＝ (max−min)/max）。
2. **「主色调」定义（★ 修订）**＝ **印泥核心质心**：掩膜内**饱和度 ≥ p75** 的像素均值 `C`。
   - 理由（Zang 实测）：掩膜**全体均值**含大量淡边像素、离纸色太近 ⇒ 两点定线**病态**（所需 `a` 达 3.3〜8.7，越限幅 ⇒ 大量跳过）；核心质心 `a` 落在 0.73〜2.10，健康。
   - **掩膜全体质心另作观察项**（`centroid_all_after`），**不作判据**（纸→纯白会整体变冷，实测掩膜均值 ΔE 9.2→20.6 变差；核心质心才精确咬靶）。
3. **双锚点仿射**：每通道解 `out = a·in + b`（**线性 RGB** 中计算、sRGB 往返），两点定线——
   - **锚点①纸**：纸区 `W` ＝ **非印泥 ∧ 亮度 ≥ p90** 的像素均值 → **`#FFFFFF`**＝`rgb(255,255,255)`（**Kevin 2026-10-11 裁定：纸色校准至纯白**）。
     - **v0.1 修订 3（采纳 Kong 实测）：纸集必须排除印泥像素** —— 高印泥占比的页上，`V≥p90` 会取到**淡印泥**，两锚点挨太近 ⇒ 蓝通道 `a` 越界（实测「limiting」占 **32.5%**）；纸集改为「**非印泥 ∧ V≥p90**」后 ⇒ limiting **14.1%**、生效张数 **33 → 61（/120 抽样）**，而 ΔE 中位不变（0.43）。
   - **锚点②印泥**：`C`（核心质心，见第 2 条）→ **`#C95021`**＝`rgb(201,80,33)`。
   ⇒ 两点定线 ⇒ 两个目标**同时**精确成立（对角增益 `out=k⊙in` 无解，已由 Kong 实测证伪）。
   - **限幅与兜底**：`a ∈ [0, 3]`、`|b| ≤ 255`（**单点可改**）；越界或 `|C−W|` 在线性空间任一分量 `< 0.02`（病态）⇒ `skipped(degenerate)`。
   - **已实测的固有代价（必须如实登记）**：纸→纯白会**整体变冷**（暖纸的蓝通道被抬得比红多）⇒ 中灰 180 → `(199,209,231)` 偏蓝；如需「视觉更自然但印泥不到靶色」，可一句话改用 **V1b**（只做纸→白的白平衡 ＋ 印泥饱和度增强）。
4. **跳过与兜底**：`ink_ratio < 2%` ⇒ **本轮不校正**，逐行标 `color_correction: "skipped(ink_ratio=<值>)"`（**不得静默**）。**待裁 R-c**：阈值 2% 是否合适。**新增待裁 R-e2**：被跳过的图是否改用**语料中位增益**做兜底归一（实测跳过率 **40%** —— 语料含释文/边款图，本就少红印泥）。
5. 目标色 **`#C95021` ＝ rgb(201,80,33)**（唯一常量、单点可改）。
6. **口径明写（消歧）**：`centroid_after` 一律在**校正前的同一印泥掩膜**上计算（勿在校正后重算掩膜——纸会掺入、质心漂向纸）；另给 `ink_ratio_after` 作观察项。

### 2.3 双色分层处理（V3｜**Kevin 2026-10-11 新口径，取代 V1a/V1b 作默认**）

> 原话：「印章的背景色部分可以对图片进行处理。图片的处理逻辑上总体可以按照双色来执行：**前景色即核心图像，要高保真，尽可能向 `#C95021` 靠拢**；**后景色为非核心图像，可以失真，尽可能向 `#FFFFFF` 纯色靠拢，允许处理和编辑**。」

1. **分层（三桶）**：`ink`＝印泥（前景/核心）｜`paper`＝**浅色**非印泥（背景，可失真）｜`other`＝**深色**非印泥（黑墨 / 边款 / 拓片 / 污渍）—— **【已裁 2026-10-11：保留原样】**（Kevin 三选一选了最安全档：**只有「浅色背景」会被压平到纯白**，`other` 桶**逐像素不动**、不得抹掉）。
2. **前景（高保真）**：只把 `ink` 像素的**色度**（Lab 的 `a*`/`b*`）向 `#C95021` 靠拢；**保留 `L*`（明度结构 / 纹理 / 边缘）** ⇒ 形状与层次不失真。
3. **背景（可失真、允许处理编辑）**：`paper` 像素**压平向 `#FFFFFF`**（阈值化 / 抬亮曲线；**允许去噪、形态学清理、抹平纸纹**）。
4. **判据（两目标 ＋ 保真）**：① 背景 → `#FFFFFF` 的 ΔE ≈ 0；② 前景核心 → `#C95021` 的 ΔE 尽量小（且**给读数**）；③ **前景保真**＝前景掩膜**前后 IoU ≈ 1**（形状不变）＋ `L*` 分布保持（给校正前后读数）。
5. **跳过口径不变**（`ink_ratio < 2%` / `degenerate` / `limiting`，逐行标记）。
6. **与 V1a / V1b 的关系**：V1a（全局双锚点仿射）与 V1b（仅纸白平衡）**降为备选口径**；V3 为默认。理由：V3 把「背景」与「前景」分开处理 ⇒ **消除 V1a 的「整体变冷」副作用**（背景是变白、不是被染色），同时让前景更贴靶色。
- 容器沿用**家法**：**RGB 8-bit ＋ Deflate 无损**（与印章线同口径；不得 JPEG-in-TIFF、不得有损）。
- 印章线：沿用**内容寻址** `<sha256[:2]>/<sha256>.tiff`（sha256 ＝ **TIFF 字节**）；`images_manifest.jsonl` 加 `color_correction` 字段（记录 applied/skipped ＋ 前后质心与 ΔE）。
- 印谱线：建议 `output/faces_tiff/<book_key>/p<页4位>_<idx2位>.tiff`（与 webp 同构、**名称寻址**，便于按页/序回指）。**待裁 R-b**。
- 落库：`stamps` **加法新增列** `img_path_tiff`（**不得 drop/rename 现有列**）；**E6 取图端点本轮不扩**（预览仍走既有 PNG/webp）。

### 2.4 重出 / 回填 / 入库

## 6. 地基实测发现 与 Zang 裁定（2026-10-11；Kong `e5a9bdb` ＋ `ops/image-colorcal/`）

### 6.1 裁定：V1 改「双锚点仿射」（原对角增益口径**数学上无解**）
- **实测（6347 件等距系统抽样 120 张）**：raw 通道增益中位 **`r≈0.98 / g=0.262 / b=0.072`** ⇒ 被我原写的 `k_min=0.5` 下限截断 ⇒ 校正后质心→靶色 **ΔE2000 中位 11.09**、`≤5` **命中 0/72**；**反事实**（放开下限）⇒ ΔE 中位 **0.011**，但**纸区色相偏移中位 −20.84°**（纸被染红）。
- **根因**：对角增益 `out = k⊙in` **只在三个 k 相等时才保白** ⇒ 「印泥咬靶色」与「纸保中性」**不可兼得**。
- **裁定**：改为**双锚点仿射**（纸锚点 `W→W`、印泥锚点 `C→#C95021`，每通道两点定线）⇒ 两目标**同时**成立；旧 `k ∈ [0.5,2.0]` 限幅作废，改为对 `a`/`b` 限幅 ＋ 越界/退化即 `skipped(degenerate)`。已并入 §2.2（**一句话可改成 V1b「先纸白平衡、再只把印泥像素的色度拉到靶色」的温和版**，代价是 ΔE 近似不为 0）。
- **旁证（正是本单要防的失败）**：**自检 15/15 PASS**，其中 `delta_e2000` 对 **Sharma/Wu/Dalal 2005 官方 34 组 Lab 色对**最大误差 **4.95e-05**（容差 1e-4）⇒ 色差实现本身可信。

### 6.2 随动口径
- **跳过率 40%**（`ink_ratio < 2%`；语料含 `yt`/`ytsw`/`yzbk`，释文/边款图本就少红印泥）⇒ **新增待裁 R-e2/R57**：被跳过的图**是否用「语料中位增益」兜底归一**（默认：**只标记、不兜底**）。
- **消歧（防下轮错算）**：`centroid_after` 一律在**校正前的同一印泥掩膜**上计算（校正后重算掩膜会让纸掺入、质心漂向纸）；另给 `ink_ratio_after` 作观察项。
- **CA-1 / CA-2 阈值条件化（★ v0.1 修订：纸锚点目标已改为 `#FFFFFF`）**：两个目标色 ⇒ **两点定线**，故判据成对成立——
  - **CA-1**：校正后 **印泥质心 → `#C95021`** 的 **ΔE2000 ≤ 5**（旧对角口径下恒不可达 0/72；双锚点口径下预期 ≈0）；
  - **CA-2**：校正后 **纸区质心 → `#FFFFFF`** 的 **ΔE2000 ≤ 5**（并给校正前后两个读数与 ΔE 改善量）；原「纸区色相偏移 ≤ 3°」降为**辅读**，不再作唯一判据。
  - 两色常量（`#FFFFFF` / `#C95021`）均为**单点可改**。

### 6.3 Zang 快算实测（12 张真 TIFF；修订 2 的依据）
- **核心质心作锚点后健康**：`a` 实测落在 **0.73〜2.10**（掩膜全体均值作锚点时要求 `a` 达 **3.3〜8.7** ⇒ 越限幅、必定大面积跳过）⇒ 故「主色调」定义改核心质心。
- **纸→纯白生效**：纸区质心 → `#FFFFFF` 的 ΔE2000 由 5.5〜13.4 ⇒ **0.13〜2.24**（显著改善）。
- **固有代价（如实登记）**：中灰 180 校正后 ≈ `(199,209,231)`（**偏蓝**）；**掩膜全体质心**到靶色 ΔE **变差**（9.2→20.6、7.3→18.0 等）——因纸→纯白使全图变冷、淡边像素更冷 ⇒ 该量**只作观察项**，判据用核心质心。
- **病态跳过**：12 张里 **2 张** `|C−W|` 过小 ⇒ `skipped(degenerate)`，另 1 张印泥 < 50 px（`skipped(ink_ratio)`）。精确比例待 Kong 全语料复测。
